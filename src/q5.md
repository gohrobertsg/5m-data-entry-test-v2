**(b)** A classmate says:

> "I installed WSL, so now I have two completely separate operating systems, Windows and Linux, running side by side, each totally independent."

Is this accurate? Briefly explain why or why not.

**Answer:**
No, this is not accurate. Windows and Linux are not isolated operating systems running side by side independently, it is more like Linux is running as a guest with specific set of rules integrated into the Windows environment.

**(c)** Explain the difference between a **terminal (emulator)** and a **shell**, and give one example of each.

It is just only a text display and input surface. For example : Window Terminal, iTerm2. Whereas shell is the program that reads the commands, interprets and does the work.
